# Synthecxhub_Project_CSV_Excel_Converter

CSV → Excel Converter

A simple and efficient Python CLI tool that reads CSV files, cleans and normalizes data, and exports the result to Excel (.xlsx) format using pandas and openpyxl.
This project is useful for data preparation, reporting automation, and learning file handling with Python.

🚀 Features

✔ Read CSV files
✔ Handle missing values
✔ Remove duplicate rows
✔ Date parsing
✔ Column renaming
✔ Export to Excel (.xlsx)
✔ Command-line arguments (CLI support)
✔ Logging and error handling

🛠 Technologies Used

Python
pandas
openpyxl
argparse
logging
